## 插件 (Plugins)

### 1. ECharts 插件 (`src/plugins/echarts.ts`)

**功能描述：** ECharts 图表库的按需导入配置，减小打包体积。

**主要特性：**

- 按需导入图表类型和组件
- 只注册项目中实际使用的图表类型
- 支持多种图表类型：柱状图、折线图、饼图、散点图、雷达图、地图、K线图等

**使用示例：**

```typescript
import { echarts } from '@/plugins'

// 创建图表实例
const chart = echarts.init(dom)
```

**导出的图表类型：**

- BarChart (柱状图)
- LineChart (折线图)
- PieChart (饼图)
- ScatterChart (散点图)
- RadarChart (雷达图)
- MapChart (地图)
- CandlestickChart (K线图)

### 表单组件 (`src/components/core/forms/`)

#### 1. ArtForm - 表单组件 (`art-form/index.vue`)

**功能描述：** 基于 Element Plus Form 的增强表单组件，支持常用表单组件、自定义组件、插槽、校验、隐藏表单项。

**主要特性：**

- 支持 Element Plus 所有表单组件
- 支持自定义组件和插槽
- 支持表单校验
- 支持响应式布局
- 支持隐藏表单项

**使用示例：**

```vue
<ArtForm
  v-model="form"
  :items="formItems"
  :rules="rules"
  :span="12"
  :gutter="20"
  label-width="100px"
>
  <template #icon>
    <ElInput v-model="form.icon">
      <template #append>
        <ArtSvgIcon :icon="form.icon"></ArtSvgIcon>
      </template>
    </ElInput>
  </template>
</ArtForm>
```

## 指令 (Directives)

### 1. v-auth - 权限指令 (`src/directives/core/auth.ts`)

**功能描述：** 权限控制指令，用于控制 DOM 元素的显示和隐藏。

**主要特性：**

- 支持后端权限控制模式
- 基于权限标识控制元素显示
- 无权限时自动移除元素（而非隐藏）
- 支持响应式更新

**使用示例：**

```vue
<!-- 只有拥有 'user:add' 权限的用户才能看到新增按钮 -->
<el-button v-auth="'user:add'">新增</el-button>

<!-- 支持多个权限（OR 逻辑） -->
<el-button v-auth="['user:add', 'user:edit']">操作</el-button>
```

**权限格式：**

- 后端模式：`menuName:authMark`（如 `user:add`、`role:edit`）
- 前端模式：从路由 meta.authList 中获取

### 2. v-roles - 角色权限指令 (`src/directives/core/roles.ts`)

**功能描述：** 角色权限控制指令，用于控制基于角色的元素显示。

## Hooks

### 1. useTable - 表格数据管理 (`src/hooks/core/useTable.ts`)

**功能描述：** 企业级表格数据管理方案，封装了表格开发中的所有常见需求。

**主要功能：**

- 数据管理：自动处理 API 请求、响应转换、加载状态和错误处理
- 分页控制：自动同步分页状态、移动端适配、智能页码边界处理
- 搜索功能：防抖搜索优化、参数管理、一键重置、参数过滤
- 缓存系统：智能请求缓存、多种清理策略、自动过期管理
- 刷新策略：提供 5 种刷新方法适配不同业务场景
- 列配置管理：动态显示/隐藏列、列排序、配置持久化

**使用示例：**

```typescript
const {
  columns,
  columnChecks,
  data,
  loading,
  pagination,
  getData,
  searchParams,
  resetSearchParams,
  refreshData
} = useTable({
  core: {
    apiFn: fetchGetUserList,
    apiParams: {
      current: 1,
      size: 20
    },
    columnsFactory: () => [
      { prop: 'userName', label: '用户名' },
      { prop: 'userEmail', label: '邮箱' }
    ]
  }
})
```

**功能描述：** 权限验证管理 Hook，提供统一的权限验证功能。

**主要功能：**

- 权限检查：检查用户是否拥有指定的权限标识
- 双模式支持：自动适配前端模式和后端模式的权限验证
- 前端模式：从用户信息中获取按钮权限列表
- 后端模式：从路由 meta 配置中获取权限列表

**使用示例：**

```typescript
// 在模板中使用

```

## 使用建议

### 1. 组件使用

- 优先使用项目提供的公共组件，避免重复开发
- 组件支持 Element Plus 的所有属性和事件，可直接参考 Element Plus 文档
- 使用 TypeScript 类型提示，提高开发效率

### 2. Hooks 使用

- 表格相关功能优先使用 `useTable` Hook
- 权限验证统一使用 `useAuth` Hook
- 主题切换使用 `useTheme` Hook

### 3. 指令使用

- 按钮权限控制使用 `v-auth` 指令
- 角色权限控制使用 `v-roles` 指令
- 文本高亮使用 `v-highlight` 指令

### 4. 工具函数使用

- 存储操作统一使用 `storage` 工具
- HTTP 请求使用封装的 axios 实例
- 路由导航使用导航工具函数
